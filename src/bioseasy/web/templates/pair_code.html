Connect the device by USB, unlock it, run the command, and tap Trust when asked.

"command not found: uv"? Install uv first

The command needs uv. Install it once, then open a new terminal window and run the command above again.

macOS or Linux:

curl -LsSf https://astral.sh/uv/install.sh | sh

macOS with Homebrew:

brew install uv

Windows (PowerShell):

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
