Where the backups are

Every path below is inside the bioseasy container. On the host it sits under the directory mounted as BACKUP_ROOT. A snapshot is hard-linked against the previous generation: copy it, never move it, or the generations still sharing its files lose them.

A backup password is required for an encrypted backup; a backup made without encryption restores without one.

Restore with Finder, on a Mac

  1. Copy (not move) {{ restore_path }} into ~/Library/Application Support/MobileSync/Backup/ (Finder: Go → Go to Folder), so it becomes a new subfolder there named exactly after the device UDID, {{ device.udid }}.
  2. Connect the device, open it in Finder, and under the General tab choose "Restore Backup", then pick the backup you just copied in. Enter the backup password when Finder asks for it if the backup is encrypted.

Restore with Apple Devices or iTunes, on Windows

  1. Press Windows key + R and open %USERPROFILE% if you use the Apple Devices app or iTunes from the Microsoft Store, or %AppData% if you use the traditional iTunes install (its Help menu shows "Check for Updates"). Apple's documentation does not name the exact backup subfolder under that root (path not verified); look for a MobileSync\Backup folder from there.
  2. Copy (not move) {{ restore_path }} into that backup folder, so it becomes a new subfolder named exactly after the device UDID, {{ device.udid }}.
  3. Connect the device, open it in the Apple Devices app or iTunes, and under the General tab choose "Restore Backup", then pick the backup you just copied in. Enter the backup password when it asks for it if the backup is encrypted.

On Windows the exact subfolder below the root varies - check both paths above.

Restore with iMazing (third party, commercial)

  1. Copy (not move) {{ restore_path }} to a folder on the computer running iMazing; it does not need to sit inside iMazing's own backup folder.
  2. In iMazing, open the device, go to its Backups view, choose "Add existing backup" (or the equivalent import action in the installed version) and point it at the folder you copied in.
  3. Select the imported backup and choose "Restore", entering the backup password when asked if the backup is encrypted.

bioseasy does not bundle, install or configure iMazing (Digidna, not affiliated with this project); its exact menu wording can change between versions, so check the "Restore a Device" section of iMazing's own guide at imazing.com/guides before relying on the steps above.

Restore with pymobiledevice3, from any computer

  1. Copy (not move) the chosen directory from the table above into an empty folder on the computer doing the restore, so the new folder contains one subfolder named exactly after the device UDID: <folder>/{{ device.udid }}.
  2. With pymobiledevice3 installed and the device connected and unlocked, run: pymobiledevice3 backup2 restore --password <backup password> <folder> (omit --password for a backup made without encryption).
  3. Confirm the restore on the device when it asks.
